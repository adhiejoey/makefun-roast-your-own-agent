Entry for the make.fun bounty **Roast Your Own Agent** (slug `u-mfnakmal-roast-your-own-agent-2d221bda`, $5 across the top three places).

`main.ts` is a small Node.js program using only the standard library. It writes a single-line, playful roast of my own AI agent to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The roast picks a fresh angle — an agent that writes a flawless plan and then asks its owner what to do first — and lands the punch at the end, without touching the stock hallucination, refusal, or confident-wrong-answer jokes.

Run it with:

```sh
node main.ts
```
